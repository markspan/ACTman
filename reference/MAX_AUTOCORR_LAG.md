# Autocorrelation lag (in minutes) beyond which "recovery" (autocorrelation dropping below the 0.2 threshold) is capped, if it never actually drops below threshold within the computed lags.

Autocorrelation lag (in minutes) beyond which "recovery"
(autocorrelation dropping below the 0.2 threshold) is capped, if it
never actually drops below threshold within the computed lags.

## Usage

``` r
MAX_AUTOCORR_LAG
```

## Format

An object of class `integer` of length 1.
