# print.actman_result

Console print method for the object returned by \`ACTman()\`. Shows a
short summary of which analyses ran and how large each result is, rather
than dumping every component's full contents.

## Usage

``` r
# S3 method for class 'actman_result'
print(x, ...)
```

## Arguments

- x:

  An \`actman_result\` object.

- ...:

  Ignored (kept for S3 method compatibility).

## Value

\`x\`, invisibly.
